Room sound for the hero (opt-in: the visitor turns it on with the speaker button in the nav).
Nothing is synthesised. The system tries these extensions in order and uses the first that exists:
.mp3, .m4a, .webm, .ogg.

day-music     the loop played in day mode.    (Jazz Rainy Lounge, Alex Morgan)
night-music   the loop played in night mode.  (2 AM Lofi Chill Ambient, Music For Videos)
lamp-click    OPTIONAL one short click, played on the lamp switch. Not added yet.
paper-rustle  OPTIONAL one very short, soft paper sound, played very quietly when a taped item is hovered. Not added yet.

The two music files were made from the originals in Downloads:
- loudness set to about -18 LUFS (quiet background), so the page's volume variables sit in a sane range;
- the last 3 seconds are crossfaded into the first 3, so the loop comes round without a click or a gap;
- mp3, 112 kbps stereo, about 1.7-1.9 MB each.
If you swap a track, keep the loop in mind (end should flow back into the start) and keep it short.

Both tracks look like Pixabay downloads: worth a quick check of the licence for each (the names carry Pixabay-style ids).
The button's tooltip credits the artist while a track plays.
