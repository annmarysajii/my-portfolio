Textures used by the hero lighting layers.

window-shadow.webp   PLACEHOLDER (generated). Replace with the real window-blind / window-frame
                     shadow photograph. Mostly white, shadows dark: it is used with mix-blend-mode:
                     multiply at ~16% opacity, so white = no effect. Suggested size 1600x1000 or larger,
                     soft edges, light angled from the top left. Keep the same file name, WebP or AVIF.

rain-streaks.webp    PLACEHOLDER (generated). Replace with a real, faint rain-on-glass light pattern.
                     Transparent ground with pale streaks/beads, 800x800, seamless top to bottom (it
                     loops by sliding down exactly 800px), shown on the mat only at ~3.5% at night.
                     If you change its height, change --rain-tile in the hero CSS to match.
